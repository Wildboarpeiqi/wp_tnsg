## FAQ 字段清单（老方法，你照着建）

### 一、创建 FAQ 自定义文章类型（ACF 后台 → 自定义文章类型 → 新建）

| 项目           | 值                                  | 说明                                                            |
| ---------------- | ------------------------------------- | ----------------------------------------------------------------- |
| 文章类型名称   | `faq`                           | 必须小写，决定 URL /faq/                                        |
| 标签           | FAQ                                 | 后台显示名                                                      |
| 复数标签       | FAQs                                |                                                                 |
| 公开           | 是                                  |                                                                 |
| **归档** | **是**                        | ​**关键：开启后才有 /faq/ 列表页**​（否则列表页出不来） |
| 重写 slug      | faq                                 | URL：列表 /faq/，详情 /faq/问题-slug/                           |
| 支持           | 标题、编辑器、摘要                  | 标题=问题，正文=答案，摘要=列表卡片描述                         |
| 分类法         | **不选**                      | 按你说的，不用分类法                                            |
| 菜单图标       | `dashicons-editor-help`（问号） | 可选，后台好看                                                  |

### 二、ACF 字段（全部挂在公共字段页 62，与 page\_banner\_img / news\_banner\_img 同模式）

| 字段名称                | 类型              | 默认值                  | 说明                                                                                                                                                                             |
| ------------------------- | ------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `faq_banner_img`    | Image（返回 URL） | 选一张 FAQ 横幅图       | FAQ 列表页 banner 背景图。独立于产品的 page\_banner\_img、新闻的 news\_banner\_img，后台可单独换                                                                                 |
| `faq_banner_title`  | Text              | `FAQ`               | banner 大字标题（对应产品的 page\_banner\_title）                                                                                                                                |
| `faq_related_title` | Text              | `Related Questions` | FAQ 详情页侧栏列表标题。​**不能复用 62 已有的 news\_related\_title**​（那是文章详情页的，会重名冲突，和当初 related\_title 给产品、news\_related\_title 给新闻一个道理） |
