## 关于我们页 · ACF 字段清单（v1）

### 先说清楚 3 件不用你建的事

| 事项                       | 说明                                                                                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Banner 背景图**    | 你已建好 `site_banner`（挂在所有页面上），About 页面建好后直接在页面后台填图即可；​**标题 = 页面标题（About Us），面包屑 HOME > ABOUT US 自动生成**​，都不需要字段 |
| **公司名**           | 复用公共字段页 62 的 `about_company`（首页也在用），About 页模板自动读取，**不用新建**                                                                               |
| **Our service 区块** | 复用首页已建的 `svc_1~5` + `svc_cta_*`，代码从首页读取，About 页**零重复录入**                                                                                   |

### 需要新建的字段（位置规则：​**页面 == About Us**​，slug 用 `about-us`）

**① 公司介绍 Intro 区块**

| 字段名称                      | 类型         | 默认值                | 说明                                                                                                     |
| ------------------------------- | -------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| `about_intro_title`       | Text         | `About Us`        | 左列顶部小标题                                                                                           |
| `about_intro_desc`        | Textarea     | 见附录①              | 公司介绍正文（一个字段，​**不含标题**​；段落间空一行自动分段；容器固定高度，超出下滑，不会拉高） |
| `about_intro_img`         | Image（URL） | `about-intro.jpg` | 右侧图片（容器 16:9）                                                                                    |
| `about_intro_video_embed` | Textarea     | `(空)`            | 右侧视频嵌入代码（YouTube iframe 等，​**有值优先于图片**​）                                      |
| `about_intro_video_file`  | File         | `(空)`            | 右侧视频 mp4 文件（embed 为空时用；容器 16:9 加载前保持高度）                                            |

**② CNC Machining 区块**

| 字段名称             | 类型     | 默认值               | 说明                                                                                                    |
| ---------------------- | ---------- | ---------------------- | --------------------------------------------------------------------------------------------------------- |
| `cnc_title`      | Text     | `CNC Machining`  | 右列标题                                                                                                |
| `cnc_desc`       | Textarea | 见附录②             | 右列段落（材料利用率 50% 那段；固定高度，超出下滑）                                                     |
| `cnc_imgs`       | Group    | `(空)`           | 组内 `img_1` \~ `img_6`：左列轮播图（3 秒自动 + 左右箭头）                                      |
| `cnc_quote_text` | Text     | `Get Free Quote` | 按钮文字（点击弹出询盘弹窗，​**与 header 的 Contact Us 同一个弹窗**​，表单逻辑复用 header.php） |

**③ Certificate 证书区块**

| 字段名称               | 类型     | 默认值            | 说明                                                                                              |
| ------------------------ | ---------- | ------------------- | --------------------------------------------------------------------------------------------------- |
| `about_cert_title` | Text     | `Certificate` | 区块标题                                                                                          |
| `about_cert_desc`  | Textarea | 见附录③          | 区块描述文案                                                                                      |
| ~~证书图~~          | —       | —                | ​**不需要建**​：证书轮播直接调用 certificate CPT（和首页/产品详情页同一套证书，点击放大） |

**④ Testing equipment 检测设备区块**

| 字段名称         | 类型  | 默认值                  | 说明                                                                                                                             |
| ------------------ | ------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `test_title` | Text  | `Testing equipment` | 区块标题                                                                                                                         |
| `test_imgs`  | Group | `(空)`              | 组内 `img_1` \~ `img_6`：设备图（左大图 + 右缩略图​**共用这一组**​，点击缩略图切换大图并顺延循环，3 秒自动）     |
| `test_names` | Group | `(空)`              | 组内 `name_1` \~ `name_6`：对应 6 台设备名（默认值见附录④，​**空则隐藏名称**​；缩略图底部和左大图显示同一名称） |
